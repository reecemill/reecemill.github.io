Satellite Collision Risk Prediction

Complete

Forecasting whether a satellite close approach becomes dangerous, using only the data available at least two days before it happens.

Operators get a stream of Conjunction Data Messages before a predicted close approach, each one a refreshed collision estimate. Deciding to manoeuvre is expensive either way: it burns fuel and shortens mission life, but ignoring a real threat can cost the spacecraft. The work uses real, anonymised operational records from ESA missions.

The simple rule of assuming the latest risk won't change is right by definition for the quarter of events that get no updates after the forecast point. On the rest it scores an F2 of only 0.49. A gradient-boosting model, including trend features for how the risk and miss distance have been moving, doesn't beat it overall, but consistently raises at least a third fewer false alarms at the cost of a few more misses. Every result is averaged over five train/test splits, after a single split showed a win that turned out to be luck.

QuizBank

Complete

A question bank that grades quizzes online, finds broken questions, suggests scores for written answers, and groups questions by topic.

Built on my senior design project: I rewrote the Canvas quiz importer as a tested parser and built a Django app where instructors share quizzes that grade themselves. On top of it, item analysis flags questions whose answer key is probably wrong, a ridge model on sentence-embedding features suggests essay scores, and k-means on embeddings groups questions into topics. Each is measured against baselines: the essay model on real graded answers to questions it never saw, the flags on simulated classes where the truth is known, and the topics against the known subjects of MMLU questions.

Orbit Determination & Trajectory Prediction

Complete

Measuring how wrong public satellite orbits are, learning and removing the error, and fitting an orbit myself with detailed physics.

Almost everyone outside a satellite's operator tracks it with a TLE, run through the simplified SGP4 model. Against ESA's centimetre-accurate orbits for the Sentinel-1 satellites, a fresh TLE is already off by about half a kilometre, and most of that error is a half-day wave from Earth's oval equator, which SGP4 leaves out. A gradient-boosting correction, tested on months it never saw, removes about half of it, and still removes a quarter on a sister satellite it was never trained on.

I also wrote a numerical propagator (gravity field to degree 40, Sun and Moon) and a batch least-squares fit, and fitted orbits to simulated radar tracking. Over eight test dates, the result is 23 m off in the first six hours after tracking ends, against 549 m for the newest TLE.

MMA-HUB

Complete

Every UFC fighter and event since UFC 1, with a model that predicts fights, including dream matchups between any two fighters.

A .NET scraper pulls fighters, events and bouts from the Cito API into Postgres, and an ASP.NET Core site shows records, career stats, every card with results, and the model's pick for each bout. The public demo runs on a read-only SQLite snapshot in a Docker container on Hugging Face.

The model is a logistic regression on each fighter's UFC history (an Elo rating, win rate, recent form, finishes, activity), built only from fights before the one being predicted. Tested once on 1,300 fights it never saw, it picks 59.8% of winners, no better than backing the fighter with the better win rate, but its probabilities are calibrated: when it gives the favorite 60–70%, the favorite wins 67% of the time. An early version picked 71%, which turned out to be duplicate events in the source data leaking results into the history.
